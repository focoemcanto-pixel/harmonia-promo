# harmonia-promo

Landing page promocional do **Foco em Harmonia** — versão com copy de alta conversão e urgência.

## Stack

- Next.js App Router
- TypeScript
- Cloudflare Pages (`output: 'export'`)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# gera a pasta /out para deploy no Cloudflare Pages
```
